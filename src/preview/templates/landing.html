Every space runs the identical open source stack — the size only changes how much RAM and CPU it gets. Need something bigger, or your own domain? That's a setting you can change later. (This is a styling preview; the buttons don't provision anything.)

Set up for you

Imbue provisions a dedicated server, points DNS at it, and installs Cloud in a Bottle — you land on a working dashboard.

Yours to keep

It's your instance on your key. Walk away with it, move it to your own hardware, or run your own apps — same software as every other path.

Kept running

Updates and upkeep are handled. Paying Imbue is optional and is what keeps the open source project funded.

Managed spaces are run by Imbue, the team behind Cloud in a Bottle. The software is open source under AGPL-3.0 — free to run yourself, on any of three paths.
